# CHROMA

Терминал для исследования токенов Solana: поиск кандидатов, восемь открытых проверок, очередь приоритетов и история наблюдений.

## Запуск

Нужен [Node.js 22+](https://nodejs.org/). Установка пакетов и ключи API не требуются.

```bash
git clone https://github.com/Nekt-0/CHROMA.git
cd CHROMA
node src/cli.mjs demo
```

В интерактивном терминале откроется полноэкранное демо. Для статического вывода: `node src/cli.mjs demo --once`.

Демо показывает пять вымышленных целей и не обращается к сети. Балансы 277.78 → 310 SOL взяты из предоставленного текста поста. Разница +32.22 SOL и рост +11.6% — это заявленные экранные показатели, а не подтверждённая прибыль. Исходное видео и чеки сделок в проект не включены.

## Живые данные

```bash
node src/cli.mjs doctor --probe
node src/cli.mjs scan --discover --limit 5
node src/cli.mjs watch --discover --interval 30
```

Данные читает публичный DEX Screener API. Можно задать конкретные адреса mint через `--tokens A,B`. Программа выбирает пару с наибольшей заявленной ликвидностью и объясняет статус каждой цели. Проверки помогают упорядочить исследование; они не предсказывают доходность и не проверяют безопасность контракта.

Управление: ↑ / ↓ или j / k — выбор; 1 / 2 / 3 — очередь, журнал, сессия; r — обновление; e — экспорт; q — выход.

## История и отчёт

```bash
node src/cli.mjs session --start 277.78 --end 310 --captures 5
node src/cli.mjs history
node src/cli.mjs verify
node src/cli.mjs export --out exports/session.json
node src/cli.mjs export --format md --out exports/session.md
```

Журнал хранится локально в `.chroma/events.jsonl`. Записи связаны SHA-256 хешами; ошибки провайдера тоже записываются. `--dir PATH` позволяет разделять сессии. Хеши проверяют целостность локального файла, но не подтверждают достоверность торгового результата.

SOL считаются целыми лампортами. Внесения и выводы можно задать через `--deposits` и `--withdrawals`; без обоих значений поправка на внешние потоки неизвестна. Для оценки реальной прибыли нужны исполнения, комиссии, убытки и открытые позиции.
