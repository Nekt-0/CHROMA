**CHROMA: SCAN → TRACK → PRIORITIZE → RECORD.**

I built CHROMA to make the history behind a target inspectable: what entered the queue, which checks passed, what changed and what was recorded afterward.

The previously shared session displays 277.78 SOL → 310.00 SOL: a +32.22 SOL change, approximately +11.6%, with five captures reported. These are on-screen figures, not a verified trading record. Execution costs, fees, losses, open positions and deposits or withdrawals need reconciliation before any claim of realized net profit.

The first CHROMA source release includes:

→ Public Solana market reads
→ Eight explainable market checks
→ A ranked target queue
→ Timestamped snapshots and status changes
→ Local event history with integrity checks
→ JSON and Markdown receipts
→ A separate, clearly labelled five-target synthetic demo

CHROMA now has DEMO, SCAN and TRADE modes. TRADE adds Jupiter quotes, unsigned simulation and explicit swap execution after a local wallet signs a reviewed order. Scanner scores do not automatically trigger trades. The implementation does not reproduce or verify the original session; its supported transaction layouts and test coverage are documented in the repository.

Run the offline walkthrough, inspect the rules and challenge the results.

**A scanner should earn its place through repeatable results.**
